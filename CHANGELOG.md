# Changelog

## 1.0.0

Initial WeblexAI Community Edition release.

- Docker Compose deployment using the published Docker Hub image.
- Web-based setup for application settings and the first administrator account.
- Dashboard management for projects, users, provider credentials, API keys, and backups.
- Browser SDK and translation API access protected by exact accepted origins.
- Streaming translation responses for browser and API integrations.
- Google Cloud Translation, OpenAI, OpenRouter, Gemini, and Qwen provider support.
- Encrypted provider credentials and project API key rotation.
- Dashboard backup creation, download, deletion, and archive-password management.
- Docker backup and restore scripts for full deployment recovery.
